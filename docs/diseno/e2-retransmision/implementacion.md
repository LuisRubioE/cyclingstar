# E2 · La implementación, PR a PR

Lo que entra en cada PR del plan de `docs/retransmision.md` (§17.2, en el orden de §17.16), lo que se aparta del diseño y por qué, y lo que el paso siguiente tiene que saber. Cada PR añade su fila a la tabla y su apartado de notas debajo, y una línea a la cabecera de `docs/retransmision.md`.

La base de E2 es la versión de producción con el motor v91 (`b1be481`), más el diseño (`3e5dab5`). `ENGINE_VERSION` sigue en 91 y no la mueve ningún PR de E2 (D-09). Las citas de línea del diseño se escribieron contra la v89 (`9c21885`, `ce0f4d8`); cada PR las comprueba contra el código de su día, y las que se han movido van en sus notas.
